## Product structure

The source product contains eight reusable procurement prompts:

1. Requirements extraction
2. Weighted vendor comparison
3. Total-cost clarification
4. Security evidence request
5. Implementation risk review
6. Renewal meeting brief
7. Contradiction and gap scan
8. Decision record synthesis

A shared security and source-handling preamble is intended to be used before each prompt. It instructs the AI service to treat supplier documents and embedded AI-directed text as untrusted source material, avoid disclosing secrets, avoid unauthorised external actions, and cite source locations.

## Intended user and purpose

The recorded intended buyer is an operations or procurement manager. The toolkit structures analysis of user-supplied procurement records. It is a workflow aid, not a substitute for an authorised procurement decision, legal advice, privacy review, information-security approval, or human verification.
